# Project rules

Read docs/DEVELOPMENT.md for scope, status and validation limits.
Maintain the existing Windows utility incrementally. Preserve film-specific cuts,
transforms and media command arguments unless explicitly authorized. Use synthetic
fixtures; do not access private film files without task-specific permission.

Use short-lived branches, focused tests and reviewed pull requests. Local commits
are routine within approved scope. Do not publish tags or release downloads without
owner approval. Windows skips on macOS are not Windows validation.
